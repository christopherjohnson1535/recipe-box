# Finding Recipes

The home page searches as you type: pause for a moment and the list updates. Enter or **Search** also works, and the
browser's Back button returns to your previous search.

## What search looks at
Titles, descriptions, notes, **tags** and **ingredients**, so "dinner" finds recipes tagged dinner and "buttermilk" finds every recipe that uses it. A half-typed word
works too: "lasag" finds "Weeknight lasagne". The line under the box says how many recipes match.

## Tricks
- `"beef mince"` in quotes finds that exact phrase.
- `soup -tomato` leaves out recipes that mention tomato.
- `soup or stew` finds either.

## Tags
Tap a tag under the search box to show only those recipes; the number is how many recipes carry it. Tags and search
combine: search "pie" with the tag *dessert* to see dessert pies. Tap **All** to drop the tag, or **Clear search** on
the empty-results page to start over.

## Sorting
The menu next to the box offers **Best match** (only while searching), **Newest**, **A–Z** and **Quickest** (shortest
total time first; recipes with no time are last). The choice is kept in the page address, so you can bookmark it.
