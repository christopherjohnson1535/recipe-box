# Roadmap

| Phase | Done when |
|---|---|
| **1 — Recipe box (MVP)** | A household member signs in, pastes a recipe link, reviews and saves it, and finds it again by search — all from `docker compose up`. |
| **2 — Photos and AI** | A photographed cookbook page becomes a saved recipe (or, without AI, a photo plus a form). |
| **3 — Kitchen** | The iPad runs it from the Home Screen in cooking mode with the screen awake; opened recipes load in airplane mode. |
| **4 — Deploy** | Runs on a chosen host over HTTPS with CI-built images and a tested backup/restore. |
| Later | Favourites, "made it" log, step timers, cooking two dishes at once. |

Each phase is a GitHub milestone; each feature slice is an issue. Requirement IDs: `docs/REQUIREMENTS.md`.
