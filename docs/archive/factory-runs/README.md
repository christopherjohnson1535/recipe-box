# Archived factory runs

Working notes written by agents during the Phase 1 software-factory runs: plans, review findings, the `FIXES.md`
ledger, smoke tables (`FINAL-*.md`) and design audits. They are kept as history (why something was built or fixed
the way it was), not as current documentation. Nothing here describes how the app works today; for that read
`docs/SPEC.md`, `docs/API.md` and `docs/UI.md`.

| Files | What they are |
|---|---|
| `plan-*.md`, `SCAFFOLD.md` | Per-slice plans and the scaffold check |
| `*-code.md`, `*-security.md`, `phase1-*.md`, `auth-forms.md` | Independent reviewer findings |
| `design-audit*.md` | Screenshot-based design audits |
| `FIXES.md` | Ledger: every finding ends as "fixed" or "skipped" with a reason |
| `FINAL-*.md` | Final smoke and screenshot tables per slice |

Future run notes go in a new folder here, `docs/archive/factory-runs/<yyyy-mm>-<slug>/`, once the run is merged;
see `docs/FACTORY.md`.
